# Reconstruction comparison notes

The main user documentation does not prescribe a separate reconstruction benchmarking protocol.

For reconstruction methods, equations, options, defaults, and implementation limits, see **[Reconstruction](/reconstruction)**.

For reproducible reporting, record the acquisition, preprocessing, reconstruction method, and method-specific parameters used. See **[Reproducibility & Citation](/reproducibility)**.

Dataset-specific tuning and evaluation helpers are available under `recon/matlab/experiments/` for users who need controlled method comparisons.
