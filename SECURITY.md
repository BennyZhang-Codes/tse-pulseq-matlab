# Security and Safety

This repository is research software, not a medical device and not a scanner safety authority. Pulseq timing checks, software PNS estimates, and CI results do not replace scanner-side limits, RF/SAR review, local policy, phantom validation, or ethics approval.

## Reporting

For a software security issue, use GitHub's private security-advisory reporting flow when it is available for this repository. Otherwise, contact the maintainer privately through the GitHub profile before opening a public issue.

Do not post scanner credentials, patient information, raw identifiable imaging data, private Siemens software, or site-specific security details in issues, pull requests, logs, or attachments.

## Scanner and sequence safety observations

If an observation concerns RF heating, SAR, gradient/PNS behavior, unexpected scanner behavior, image artifacts during scanning, or possible volunteer/patient risk:

1. Stop the affected scan protocol and follow local scanner and institutional procedures.
2. Do not rely on this repository or GitHub discussion for urgent guidance.
3. Report through the appropriate scanner vendor, MR safety, and institutional channels.
4. After de-identification and local review, a GitHub issue may describe the software reproduction case and non-sensitive evidence.
